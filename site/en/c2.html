Chapter 210 steps

Creating and setting up your organization

2.1

Prepare one place for your team's data

When an employee's name and department are written in more than one file, it is hard to keep one correct copy. In KayanOS we will set up a clear description of the team: who works with us, and in which job, department and place. The apps use this data later instead of entering it again each time.

Who does it? The system setup administrator, together with the person in charge of employees. When? When the organization starts using KayanOS. If the organization already exists, start by reviewing the existing settings and data, and do not create duplicate organizations or employees.

Result of the exercise: you can open Sarah's assignment and see her job, department and place of work. We start with Sarah, then you repeat the steps for Omar and the rest of the team.

2.2

Before you start

Prepare a short list of the names of departments, places, jobs and employees, and decide who reviews it. A code is an identifier you choose to avoid mixing up names, such as HZN-HR for the Human Resources department; it needs no programming knowledge. The subdomain is the part you choose for your organization's address, such as hzn in hzn.kayanos.app.

2.3

Step 1: Create the organization

From the sign-in screen, open “Create Organization”. This step is for the organization's owner or the administrator who sets it up for the first time, not for every new employee. Follow the four steps:

  1. 1
    Contact: choose email or phone number and enter it.
  2. 2
    Verify: enter the 6-digit code. The code is valid for 10 minutes, and you can ask for a new code after one minute.
  3. 3
    Admin: type your name, and a password if you want.
  4. 4
    Organization Details: the subdomain, the name, the country, the number of employees and the logo.

After you finish creating it, you move to your new organization's address to sign in. Check: open the new address with the administrator account, and make sure the organization name is correct. Keep the address for your team to use; the organization name alone is not enough to reach it.

Subdomain rules

From 3 to 63 characters: lowercase English letters, numbers and the hyphen (-), and it must not start or end with a hyphen. It must not be in use already, and some words are reserved, such as admin and www.

2.4

Step 2: Organization settings

From the App launcher, open Settings, then Management, then Organization settings. The goal is for the team to see the times and language that suit its work.

In the Horizon example, choose Asia/Damascus for the timezone, Arabic for the default language, and the start day of week your organization uses. Save the changes, then open the settings again to make sure the values were kept. Review these options before entering the team or following working hours.

2.5

The order of the basic data

You find all of it in the HR app. The order matters because some records point to others:

Start reading from “Assignments” at the top of the tree. The arrow shows the record that the item above it is linked to; the practical order of entry starts with the required records before you create the assignment.

  • Required: an assignment is saved only with an existing member and position.
  • Optional but recommended: linking the position to its node and location. Start with them so you can choose them when you create positions.
  • Hierarchy: the parent node before the nodes under it, and the same for locations.
  • Shifts: optional here; Section 3.4 of the HR chapter explains them.
2.6

Steps 3 to 6: Add your first employee in their job

Start by adding data by hand to learn the steps. A list shows the people or jobs, a record is the page of one item in it, and a field is a box such as the name. When you choose a department or an employee from a list inside the form, choose the existing item instead of typing a new name that is not linked to it.

Prepare the place of work and the department

  1. 1
    Open “HR”, then “Core”, then “Locations”, and choose to add. Type the code HZN-DAM and the name “Head Office, Damascus”. Choose the right location type from the available options, then the country, state, city and the actual address. Save, and go back to the list to make sure the location appears.
  2. 2
    Open “Core”, then “Nodes”, and add “General Management” with the code HZN-GM, and save it. Then add “Human Resources” with the code HZN-HR, choose “General Management” in the “Parent” field, then save.

The result: the department has a clear place in the organization's structure. If the parent node does not appear in the choices, make sure you saved it first and that you are working in the same organization.

Prepare the job, then the person, then the assignment

  1. 1
    Open “Workforce”, then “Positions”, and choose to add. Enter HZN-P-01 and “HR Manager”, choose the “Human Resources” node and the “Head Office, Damascus” location, then save.
  2. 2
    Open “Workforce”, then “Members”, and choose to add. Enter the employee ID 0001 and the name “Sarah Al-Khatib”. The seat type sets the account's usage category; choose “Full seat” for this example, and add the real contact method when you set up a real employee. Save and make sure Sarah appears in the list.
  3. 3
    Open “Workforce”, then “Assignments”, and choose to add. Choose Sarah in the “Member” field, and “HR Manager” in the “Position” field. Enter the start date and the employment type that fit; for practice you can use 2026-10-01 as the start date. Save, then open the assignment again.

Check: the assignment shows Sarah's name and her correct position. Sarah being in the members list does not by itself mean she was assigned to a job. If you cannot find her in the choice list, search by employee ID and make sure her record was saved.

The code is unique

Do not repeat a code within the same list, and do not change it when you correct the name of an existing record. For members, use the agreed employee ID. A clear name and a fixed code help you choose the right department or person later.

Importing from Excel

Use import when you have a large and correct list. Try one row first and check the result, then complete the rest of the file. This is an alternative to manual entry, not an extra step required after entering the employees.

  1. 1
    Open the entity page, such as “Positions”, choose import, then download the template.
  2. 2
    Columns marked with * are required.
  3. 3
    Leave empty the columns the system fills in: “ID”, “Label”, and every column that starts with the word “Active”, such as “Active Positions”.
  4. 4
    In link columns, such as “Position” or “Node”, write the Label exactly as it appears in the system.
  5. 5
    Review the preview before confirming.
Update instead of duplicate

If you import a file with a code that already exists, the existing record is updated and no new record is created. To correct data, edit the same file and import it again with the same codes. Duplicate rows within a single file are ignored.

Members signing in to the system

After the employee is set up, they need a way to sign in. The system administrator prepares it, and the employee tests it at the organization's address. Do not take their name appearing in the list as proof that they signed in successfully.

  • The member has an email or phone: the system creates an invitation by email or WhatsApp, valid for 48 hours. They open the link and choose a password of at least 8 characters.
  • They have neither email nor phone: the admin sets a password for them, and they sign in with the employee ID.

Ask the employee to open the organization's address and sign in with the method set for them, then open an app they are allowed to use. If the invitation does not arrive, check with the administrator that the contact method is correct; whether the message arrives also depends on the sending channel, not just on the email or phone being there.
