Creating and setting up your organization

2.1

Setup result

Who: setup administrator with HR. Result: Sarah is linked to her job, department and location.

If the organization exists, review its data; do not create another copy.

2.2

Before you start

Prepare department, location, job and employee names.

Code: a fixed identifier, such as HZN-HR. Subdomain: the address prefix, such as hzn in hzn.kayanos.app.

2.3

1. Create the organization

From sign-in, choose “Create Organization”. The setup administrator does this once.

  1. 1
    Contact: enter email or phone.
  2. 2
    Verify: enter the 6-digit code within 10 minutes. Request another after one minute.
  3. 3
    Admin: enter your name and an optional password.
  4. 4
    Organization Details: enter subdomain, name, country and staff range; optionally add a logo. Complete creation.

Check: sign in at the new address as administrator and confirm the organization name. Keep the address for the team.

Subdomain

Use 3–63 lowercase letters, digits or hyphens. No leading/trailing hyphen, existing address or reserved name such as admin.

2.4

2. Organization settings

Open: Settings / Management / Organization settings.

For the example: choose Asia/Damascus, Arabic and your working week’s start day. Save, then reopen to check.

2.5

Data order

  • An assignment requires a saved member and position.
  • Unit and location links are optional and recommended; prepare them first.
  • Create parent units and locations before their children.
  • The shift is optional here; see Section 3.4.
2.6

Add your first employee

Screenshots show unsaved Arabic forms; * means required. Sections may vary; search by page name.

List: many records. Record: one person or job. Field: an entry such as a name. Select existing records in link fields.

Location and department

  1. 1
    Open HR / Core / Locations. Add HZN-DAM, “Head Office, Damascus”. Complete type, country, state, city and address; save and check the list.
  2. 2
    In Core / Nodes, add “General Management”, HZN-GM, select its type and save. Add “Human Resources”, HZN-HR, select General Management as parent, then save.

Job, person and assignment

  1. 1
    Workforce / Positions: add HZN-P-01, “HR Manager”. Select the unit and location above; save.
  2. 2
    Members: add “Sarah Al-Khatib”, ID 0001, full seat. Add real contact details for a real employee; save.
  3. 3
    Workforce / Assignments: select Sarah and the position. Enter employment type and start date; example: 2026-10-01. Save and reopen.

Check: Sarah and her position appear. If an option is missing, check that it was saved and search by code.

Keep codes unique within a list; do not change them when correcting names.

Excel import

An alternative to manual entry. Try one row first.

Fill * columns. Leave ID, Label and Active columns for the system. Copy link labels exactly from the list.

Update or new record?

An existing code updates its record. A new code creates another record; keep codes when correcting data. Duplicate rows in the file are ignored.

Employee sign-in

  • With email or phone: an email/WhatsApp invitation lasts 48 hours. The employee opens it and sets a password of at least 8 characters.
  • Without email or phone: the administrator sets a password; the employee signs in with their employee ID.

Check: the employee signs in at the organization address and opens an allowed app. If the invitation is missing, check contact details and the sending channel.
