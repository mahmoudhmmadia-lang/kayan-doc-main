\chapter{Apps \& Navigation}
\label{ch:builder-navigation}

\section{What will you set up in this chapter?}
\label{sec:builder-navigation-intro}

Publishing a record type is not enough for the team to use it; members must find it where they expect it. This chapter explains two pages: “Apps \& Navigation”, which arranges the apps and their sections in the menu and shows or hides them, and “Work navigation”, which decides what each member sees first when they sign in.

\begin{rcnote}[Example: Horizon]
After publishing “Visit requests”, the system administrator adds the “Branch services” app and places a section in it that shows the requests, so Omar Haddad finds them in the menu without searching.
\end{rcnote}

\section{Pages in this chapter}
\label{sec:builder-navigation-pages}

Both pages stand on their own in Builder's “Core” section. Start with the first to arrange the menu, then use the second when you want a clearer experience for each role.
