\chapter{Dashboards \& reports}
\label{ch:builder-dashboards}

\section{What will you build in this chapter?}
\label{sec:builder-dashboards-intro}

Once records accumulate, managers need figures that summarize the work, such as the number of open or overdue requests. This chapter explains dashboards that you build from visual widgets, pages that publish analytics inside apps, and dashboards and reports built with AI assistance.

\begin{rcnote}[Example: Horizon]
Horizon builds a “Visits follow-up” dashboard that shows the number of visit requests in each status, so every morning Sarah Al-Khatib sees the requests waiting for her review.
\end{rcnote}
